DealForma (dealforma.com) — curated biopharma deal database covering licensing, R&D, academic, M&A, spin-outs, asset purchases, venture/IPO/follow-ons, company profiles, pipeline history, drug sales figures, clinical/regulatory context. Filterable by stage, modality, indication, target, territory. Supports data export; site-licensed customers get data feed/API for internal dashboards. Daily human-curated, Tableau dashboards, natural-language search.

**Integration priority (user-defined 2026-04-01):**
1. Manual comp analysis + dashboard context (immediate, low-risk)
2. Slow-moving shadow features for M&A / valuation (shadow-first)
3. Bounded dealability overlay only if shadow evidence supports it

**Key principle:** Treat as fundamental comp / precedent layer, NOT a fast tactical signal. Deal data is slow-moving, terms often incomplete, contingent values distort comparability.

**Best fit use cases:**
- M&A probability / "dealability" context (comp-aware features)
- Valuation comps / event interpretation (takeout sanity, CVR benchmarking)
- BD / commercialization context (operator-facing dashboard cards)

**Not for:** Direct daily DEM rerank weight or high-frequency signal.
